# 青瞳 · Qingtong Codex Pet

A Codex-compatible v2 animated desktop pet based on a silver-gray and warm-beige cat with blue-green eyes.

- Sprite format: Codex pet v2
- Atlas: 1536 × 2288
- Grid: 8 columns × 11 rows
- Cell size: 192 × 208
- Animations: 11 rows, 73 frames, including 16 look directions
- Background: transparent RGBA
